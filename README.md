# AyushOS

AyushOS is a web-based operating system interface featuring interactive window management, dev logs, and a projects hub.

🚀 **Live Demo:** [https://godgamer123456.github.io/ayush-os/](https://godgamer123456.github.io/ayush-os/)

## Features
* **Window Management:** Multiple draggable, focusable desktop windows.
* **Dev Logs:** Interactive log sidebar with dynamic content rendering.
* **Projects Hub:** Categorized project showcase with dynamic technology tags.
* **System Clock:** Real-time clock update loop integrated into the top status bar.

## Tech Stack
* HTML5
* CSS3 (Glassmorphism & Flexbox/Grid)
* Vanilla JavaScript (DOM Manipulation & Event Handling)
